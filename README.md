# vlek-website

De website van Vlek, de agent van Mark Meijerman.

Statische site: HTML en een stylesheet, geen build-stap, geen dependencies, geen externe
requests. GitHub Pages serveert de root van de `main`-branch.

Lokaal bekijken:

```
python3 -m http.server 8123
```

En open `http://localhost:8123/`.
